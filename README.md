Stellar Soroban implementation of the [ProofOrPay](../pact_protocol_spec.md): accountability stake pools, AI-assisted proof scoring, and optional reputation ledger.

## Layout

| Path | Purpose |
|------|---------|
| `contracts/reputation_ledger` | `ReputationLedger` — wins / slashes / leaderboard |
| `contracts/proof_badge` | `ProofBadgeNft` — soulbound proof NFTs minted on successful settlement |
| `contracts/stake_pool` | `StakePool` — pools, stakes, IPFS proofs, settlement, badge minting |
| `frontend/` | Next.js 14 — wallets, pools UI, `/api/score` (Claude + on-chain verdict) |
| `scripts/` | Deploy / invoke helpers |

## Contracts

```bash
cd contracts
cargo test --manifest-path stake_pool/Cargo.toml
```

Build WASM:

```bash
cd contracts
stellar contract build --manifest-path proof_badge/Cargo.toml
stellar contract build
cargo test --manifest-path stake_pool/Cargo.toml
```

**New on-chain features**
- `Pool.cover_cid` — IPFS cover image for pool cards
- `Member.proof_cid` / `proof_image_cid` — IPFS metadata + artwork on `submit_proof`
- `Member.proof_nft_id` — soulbound badge minted in `settle_pool` for shippers
- `set_pool_cover` — creator can update cover CID after create

Deploy order: **ReputationLedger** → **ProofBadgeNft** → **StakePool**, then:
1. `ReputationLedger::init(stake_pool)`
2. `ProofBadgeNft::init(stake_pool)` (stake pool is minter)
3. `StakePool::init(token, reputation, proof_badge, verifier)`

## Frontend

```bash
cd frontend
cp .env.example .env.local   # fill contract IDs + keys
npm install && npm run dev
```

| Env | Role |
|-----|------|
| `NEXT_PUBLIC_STAKE_POOL_ID` | Deployed StakePool contract |
| `NEXT_PUBLIC_REPUTATION_LEDGER_ID` | Optional UI reads |
| `NEXT_PUBLIC_PROOF_BADGE_ID` | Proof NFT contract (`/proofs` page) |
| `NEXT_PUBLIC_XLM_TOKEN_ID` | Testnet XLM SAC (default in `constants.ts`) |
| `PINATA_JWT` | Server: real IPFS pinning (`/api/ipfs/upload`) |
| `ANTHROPIC_API_KEY` | Claude scoring (`/api/score`) |
| `STELLAR_VERIFIER_SECRET_KEY` | Signs `record_ai_verdict` (must match on-chain verifier) |
